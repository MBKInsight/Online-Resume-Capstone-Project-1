# Online-Resume-Capstone-Project-1

# 📌 Project Description
This project is a personal online resume website built using only HTML5 as part of Capstone Project 1 from a Web Development Bootcamp.

The website showcases my professional profile, education, work experience, technical skills, certifications, hobbies, and contact information in a clean and structured multi-page format.

- Multi-page website navigation

- Education section
- Work experience section
- Skills section

- Profile image
